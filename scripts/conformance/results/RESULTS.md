## (b) Hash + JSON Schema baseline against the verifiers

The baseline accepts a vector when every document it declares validates against its committed JSON Schema (Ajv 2020-12, set up as in `verify.mjs`) and every digest the record carries recomputes. It checks every digest that the valid vectors of the same schema declare: RFC 8785, python-json-v1 or file bytes. It replays nothing. *Strict* reads JSON as `verify.mjs` does, rejecting duplicate keys. *JSON.parse* keeps the last of duplicate keys. Both reject NaN and Infinity; Python's `json.loads` accepts them by default. *Verifier rejects* counts exit codes other than 0.

## (c) Single-leaf mutations

Every JSON leaf of every valid vector is changed once: integer +1, float +0.125 (x2 when |x| >= 1e6), string + `x`, boolean flipped, null to `x`. The edited record goes through its verifier; *detected* means an exit code other than 0. **Stale** leaves every digest as it was. **Resealed** recomputes every digest the manifest declares for that vector, innermost first, as someone who edits a record and re-hashes it would; in a directory vector it rewrites the edited file's SHA-256 in `provenance.json`. Digest fields are not mutated. In directory vectors only JSON files in compact sorted form are mutated; JSONL files and `provenance.json` are not.

### What the mutation rates show, and what they do not

- Digests detect change, not forgery: whoever edits a record can recompute its hashes ([DECISION_RECORDS.md](../../../docs/DECISION_RECORDS.md#compatibility-and-limits)). A resealed edit is caught only when replay recomputes something from the edited field.
- Fields no recomputation depends on stay bound only by a signature (`--require-signature`): free text such as review and event notes or question instructions, caller-supplied labels such as `recommendation.model`, `question_version`, `proposed_by` and `produced_by.version`, and inputs whose edit leaves the recomputed verdict unchanged. The lists above name them for this corpus.
- One edit per value type, one leaf at a time, on vectors written by the same authors as the verifiers. The rates describe this corpus and operator, not records in general or an adversary who edits several fields together.
