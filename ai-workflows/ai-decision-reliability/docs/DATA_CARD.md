# Synthetic data card

- **Candidate:** pre-release package 0.1.5 using specification 0.1.3, developed under `ai-workflows/ai-decision-reliability/` in `BichengWang/ai-decision-system`. The generator and benchmark semantics are unchanged from 0.1.4. No accepted public project release, annotated release tag, deployment, or adoption is claimed.
- **Source:** `relia/generator.py`, seed 20260917. No real persons, customers, merchants, employers, or transactions are represented.
- **Offer task:** 120 simulated days x 2,500 sessions; 240 synthetic merchants in 6 categories. Logged discounts are randomized within the policy constraints, so response labels are unconfounded by design.
- **Ground truth:** a known response function with deliberate non-linear structure (saturating discount response for large baskets, a distance threshold, and an hour-by-category interaction). Because the truth is known, `true_p` is stored for diagnostics and is never used for fitting.
- **Shift:** from day 96, basket values are scaled by 1.12 and the response function changes for one category and for discount sensitivity.
- **Input guard:** the raw data also contain labels, identifiers, metadata, synthetic truth, and three named proxy fields. Model and policy code receive an authorized-feature allowlist view; every other read through that view is counted and release-blocking. The guard does not detect code that bypasses the view, so code review and the controlled pipeline remain required.
- **Ranking task:** 4,000 queries x 20 candidates, graded relevance 0-3, with a similarity x intent-match interaction.
- **Human-review control fixture:** 16 deterministic boundary cases separate from model fitting and test metrics, with expected labels stored independently of the router; 12 must route and 4 nonrequired controls must not route.
- **Integrity:** `dataset_hash` (SHA-256 over all columns rounded to 1e-10) is recorded in `results/MANIFEST.json`.
- **Reproducibility scope:** for two fresh runs in one executing environment, `results.json` and `MANIFEST.json`—and the SHA-256 of each file—must be byte-identical. Machine-dependent `runtime.json` is excluded. Equality with the stored result hash is limited to the attested producing environment and exact dependency artifacts; elsewhere, freeze every compared numerical field's tolerances before execution, including per-seed metrics, and require decisions, gate dispositions, counters, versions, seeds, exclusions, and dataset identity to match. A dataset discrepancy requires investigation rather than a widened metric tolerance. Follow [`REPRODUCE.md`](REPRODUCE.md).

- **Known limits:** the synthetic world is far simpler than any production marketplace; it omits strategic behavior, inventory, supply response, seasonality beyond a weekly cycle, and any legal or regulatory constraint.
